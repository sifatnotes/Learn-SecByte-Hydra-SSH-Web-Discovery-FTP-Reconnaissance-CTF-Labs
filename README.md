## Learning Path

A practical progression through this collection is:

1. Start with **Source Sleuth 2** and **Disclosure Drift** to practice information discovery.
2. Continue with **Brute the Path**, **Hidden Paths Web Discovery**, and **DIRB Dive** for web path enumeration.
3. Practice **Wordlist Recon Riddle** for wordlist-oriented reconnaissance.
4. Explore **Intruder Sprint** for web security testing concepts.
5. Study **Hydra Force Service Password Crack** for authentication testing concepts.
6. Continue with **SSH Keyhole** to understand SSH key-related workflows.
7. Finish with **Anonymous FTP Relay**, **FTP Footprints 2**, and **Filevault Fracture** for FTP and file-security practice.

This progression moves from basic discovery toward more focused authentication, web enumeration, and infrastructure-related security exercises.

## How to Use the Labs

- Read each lab's instructions before beginning.
- Use the labs only in authorized CTF or training environments.
- Keep notes on commands, observations, discovered paths, and lessons learned.
- Where tools such as Hydra or DIRB are involved, understand what each option does instead of relying only on automated output.
- For web labs, record discovered endpoints and relevant application information systematically.
- For SSH and FTP labs, document the authentication and service behavior you observe.
- Never apply techniques learned here against systems without explicit authorization.
